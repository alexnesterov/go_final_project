# Планировщик задач

Веб-сервер на Go для управления задачами с поддержкой повторяющихся событий.
Реализует REST API и предоставляет готовый веб-интерфейс.

## Запуск локально

Требования: Go 1.22+

```bash
git clone https://github.com/alexnesterov/go_final_project
cd go_final_project
go run ./cmd/app
```

Сервер запустится на порту `7540`. Откройте в браузере:

```text
http://localhost:7540
```

База данных создаётся автоматически в файле `scheduler.db`
в текущей директории.

## API

| Метод    | Путь              | Описание                        |
|----------|-------------------|---------------------------------|
| `GET`    | `/api/nextdate`   | Следующая дата по правилу       |
| `POST`   | `/api/task`       | Создать задачу                  |
| `GET`    | `/api/tasks`      | Список задач                    |
| `GET`    | `/api/task`       | Получить задачу по `id`         |
| `PUT`    | `/api/task`       | Обновить задачу                 |
| `DELETE` | `/api/task`       | Удалить задачу                  |
| `POST`   | `/api/task/done`  | Отметить задачу выполненной     |

## Запуск тестов

Сначала запустите сервер локально, затем выполните тесты.

Настройки тестов находятся в `tests/settings.go`:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `Port` | `7540` | Порт сервера |
| `DBFile` | `../scheduler.db` | Путь к БД |
| `FullNextDate` | `false` | Повтор по дням недели (`w`) |
| `Search` | `false` | Поиск задач |
| `Token` | `""` | JWT-токен авторизации |

Запуск всех тестов:

```bash
go test ./tests/...
```

Запуск конкретного теста:

```bash
go test -run ^TestNextDate$ ./tests
```
